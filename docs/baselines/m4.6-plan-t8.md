### 122 acceptance run (2026-07-18, widened grid, 23 points)

`T8_POINTS=60 scripts/benchmark.sh plan`, GPU idle, ctx {2048…131072} ×
ubatch {256…8192}. llama's own `ROCm0 compute buffer size` per point
confirms the fit at the PR #118 points (342.50 / 604.33 / 1080.34 MiB
reproduced exactly). **The ≤ 256 MiB total-delta gate did not pass**: total
deltas +444…+880 MiB, with per-point ws residual scattering ±1.5 derived-K
slabs (−415…+1 681 MiB) at fixed (ctx, ubatch) — the error is not the ws
term (llama's compute buffer matches the fit) but how the caller-added
`(K+1) × slab` device-cache capacity maps to actually-resident VRAM.
Follow-up: instrument per-term engine allocations (resident expert-slab
bytes from engine stats instead of free-VRAM deltas) before re-gating T8.
Also fixed here: the sweep prompt (≈2 173 tokens) overflowed grid ctx 2048;
the prompt now scales with the point's ctx.
