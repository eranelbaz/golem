Machine/model/flags as `m3.5-bench.md` (RX 7900 XTX, 93 GiB RAM, GLM-5.3-Flash

--n-predict 64 --prompt Hello`, greedy, release HIP build). Cold = shards

immediate re-run. Decode timing: temporary `[m311]` eprintln around the
decode loop of `chat_turn_inner`, reverted, never committed. Single runs.

Lock arithmetic (target, per decode token): shard-lock claims 1,008 → 336,
releases 1,008 → 336, snapshot-mutex holds 1,008 → 1 per compute.

Interpretation: decode is disk/PCIe bound at this pool size (§2.4), and the
after deltas (cold −2.6%, warm +3.3%) sit inside single-run run-to-run
variance — no measurable change, not a win; the win is in the lock
arithmetic above, amortized away under I/O.
