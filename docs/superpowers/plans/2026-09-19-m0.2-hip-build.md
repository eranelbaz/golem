# M0.2 HIP Build — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scripted HIP build of the pinned vendored fork for gfx1100 (`scripts/build-substrate.sh`), a `llama-cli` smoke run on the RX 7900 XTX, and the build+smoke evidence committed under `docs/baselines/m0-notes.md` (design §14/M0.2, worklog M0.2).

**Architecture:** One shell script wraps the substrate build: it (1) parses `engine/llama-cpp.lock` for the advisory `rocm =` value and warns on `rocminfo` mismatch, **skipping** the check entirely when `rocminfo` is absent (CI/no-GPU machines — the check never hard-fails, per the M0.1-amended design §3.5); (2) configures the vendored tree out-of-tree into the already-gitignored `vendor/llama.cpp/build/` with `-DGGML_HIP=ON -DAMDGPU_TARGETS=gfx1100`; (3) builds the `llama-cli` target. The smoke run downloads a tiny GGUF into the gitignored `.m0-work/` scratch dir and runs it on the GPU; its transcript and the build log excerpt become the first content of `docs/baselines/m0-notes.md` (committed — no weights, no build artifacts in git). No Rust code changes; CI is untouched (this is a hardware task, design §12.1 "hardware tests: nightly script, not CI-gated").

**Tech Stack:** bash, cmake ≥ 3.14, ROCm 7.2.4 (`hipcc`, `rocminfo` at `/opt/rocm`), the vendored fork at pin `86ebfef2c6a0f3359a2a07d2c215d61b0fa885c9`, `curl` for the smoke GGUF.

**Spec:** `docs/tech-design.md` §3.2 (fork), §3.5 (ROCm advisory semantics), §14/M0.2; `docs/worklog.md` M0.2; `docs/adr/0001-fork-pin.md` (pin integrity).

## Global Constraints

- Build **only** the tree at `vendor/llama.cpp/`; the content hash must still match `vendor/VENDOR_SHA` — run the canonical `cs()` recipe (ADR 0001) before building and abort on drift (a drifted tree builds a different substrate than the pin claims).
- Configure flags are exactly `-DGGML_HIP=ON -DAMDGPU_TARGETS=gfx1100` plus `-DCMAKE_BUILD_TYPE=Release`. No other backend flags; Vulkan/CUDA stay off (D3).
- `rocm` lock check: advisory-minimum semantics. `rocminfo` absent → print `rocm-check: skipped (rocminfo absent)` and continue. Present → compare `/opt/rocm/.info/version` prefix against the lock value; mismatch → `WARN: ...` and continue. Never `exit 1` on this check.
- Build artifacts land in `vendor/llama.cpp/build/` (already in root `.gitignore` — verify with `git check-ignore` before building; nothing under `vendor/llama.cpp/build/` may ever be staged).
- Model weights never enter git: smoke GGUF goes in `.m0-work/` (ignored), logs quoted into the committed notes file are text excerpts only.
- Script is POSIX-bash, `set -euo pipefail`, no dependencies beyond cmake/curl/git (present on this machine and typical CI).
- Repo hygiene: fmt/clippy/test CI gates untouched (no Rust changes). The diff is `scripts/build-substrate.sh` + `docs/baselines/m0-notes.md` + worklog update.

### Task 1: Write `scripts/build-substrate.sh`

**Files:**
- Create: `scripts/build-substrate.sh` (executable)

**Interfaces:**
- Consumes: `engine/llama-cpp.lock` (`rocm = <ver>` line), `vendor/VENDOR_SHA` (`content_sha256=`, `commit=`), `vendor/llama.cpp/`.
- Produces: configured+built `vendor/llama.cpp/build/bin/llama-cli` (plus libs) — consumed by Task 2's smoke run and by M1.1's cmake-crate build later; exit 0 on success, non-zero on any abort listed below.

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# Build the pinned vendored llama.cpp fork for gfx1100 (HIP). Design §14/M0.2.
set -euo pipefail
cd "$(dirname "$0")/.."   # repo root

LOCK=engine/llama-cpp.lock
VENDOR=vendor/llama.cpp
BUILD_DIR="$VENDOR/build"
TARGET=gfx1100

# --- pin integrity: never build a drifted tree (ADR 0001 canonical recipe) ---
# The build-output dir is pruned: the canonical hash covers source, not artifacts, so
# re-runs after a (re)build still match VENDOR_SHA. Pruning changes nothing on a pristine tree.
cs() { cd "$1" && find . -path ./.git -prune -o -path ./build -prune -o -type f -print0 | LC_ALL=C sort -z | xargs -0 sha256sum | sha256sum | awk '{print $1}'; }
got=$(cs "$VENDOR")
want=$(grep '^content_sha256' vendor/VENDOR_SHA | cut -d= -f2)
[ "$got" = "$want" ] || { echo "FATAL: vendor tree drifted ($got != $want) — re-vendor per ADR 0001"; exit 1; }
pin=$(grep '^commit' "$LOCK" | sed 's/[[:space:]]*#.*//' | awk -F'= *' '{print $2}')
echo "pin-ok: $pin"

# --- advisory ROCm version check: WARN or skip, never fail (design §3.5) ---
lock_rocm=$(grep '^rocm' "$LOCK" | sed 's/[[:space:]]*#.*//' | awk -F'= *' '{print $2}')
if ! command -v rocminfo >/dev/null 2>&1; then
  echo "rocm-check: skipped (rocminfo absent)"
else
  # installed version: /opt/rocm/.info/version, falling back to hipcc's dir prefix
  inst=$(cat /opt/rocm/.info/version 2>/dev/null || true)
  if [ -z "$inst" ]; then echo "rocm-check: skipped (no /opt/rocm/.info/version)"; fi
  if [ -n "$inst" ] && [ "${inst%%.*}" != "${lock_rocm%%.*}" -o "$(printf '%s\n' "$inst" | cut -d. -f1-2)" != "$(printf '%s\n' "$lock_rocm" | cut -d. -f1-2)" ]; then
    echo "WARN: rocminfo reports ROCm $inst, lock pins $lock_rocm — advisory minimum (design §3.5); continuing"
  elif [ -n "$inst" ]; then
    echo "rocm-check: ok ($inst matches lock $lock_rocm)"
  fi
fi

# --- configure + build ---
[ -d "$BUILD_DIR" ] || mkdir -p "$BUILD_DIR"
cmake -S "$VENDOR" -B "$BUILD_DIR" \
  -DCMAKE_BUILD_TYPE=Release \
  -DGGML_HIP=ON \
  -DAMDGPU_TARGETS="$TARGET"
cmake --build "$BUILD_DIR" --target llama-cli -j"$(nproc)"

echo "BUILD-OK: $BUILD_DIR/bin/llama-cli"
```

- [ ] **Step 2: Syntax-check and guard the build dir against staging**

Run:
```bash

git check-ignore vendor/llama.cpp/build/ && echo BUILD-DIR-IGNORED
chmod +x scripts/build-substrate.sh
```
Expect: no output from `bash -n` (clean syntax) and `BUILD-DIR-IGNORED`. If `git check-ignore` exits non-zero, STOP — add `vendor/llama.cpp/build/` to `.gitignore` in this commit before ever building.

- [ ] **Step 3: Verify failure modes without a full build** (cheap, before the expensive run)

```bash
# drift abort: perturb one file, expect FATAL + exit 1, restore
echo "// drift" >> vendor/llama.cpp/README.md
scripts/build-substrate.sh 2>&1 | grep -q FATAL && echo DRIFT-ABORT-OK || { echo "DRIFT NOT CAUGHT"; git checkout vendor/llama.cpp/README.md; exit 1; }
git checkout vendor/llama.cpp/README.md
# rocminfo-absent skip: hide rocminfo via a restricted PATH AND stub cmake so the script's
# flow provably stops at the configure step (neither the script nor cmake echoes its own
# command line, so a log grep can never prove "cmake didn't start" — a stub marker can).
# Also: /opt/rocm/bin/rocminfo is the ONLY rocminfo on this box (no /usr/bin copy).
mkdir -p .m0-work/bin
printf '#!/usr/bin/env bash
echo "STUB-CMAKE-INVOKED $*" >> %s/cmake-stub.log
exit 0
' "$PWD/.m0-work" > .m0-work/bin/cmake && chmod +x .m0-work/bin/cmake
rm -f .m0-work/cmake-stub.log
PATH="$PWD/.m0-work/bin:/usr/bin:/bin" scripts/build-substrate.sh > .m0-work/rocm-skip-test.log 2>&1 && echo SCRIPT-EXITED-0 || { echo "SCRIPT FAILED"; cat .m0-work/rocm-skip-test.log; exit 1; }
grep -q "rocm-check: skipped" .m0-work/rocm-skip-test.log || { echo "ROCM-SKIP MISSING"; cat .m0-work/rocm-skip-test.log; exit 1; }
grep -q '^STUB-CMAKE-INVOKED -S vendor/llama.cpp' .m0-work/cmake-stub.log && echo ROCM-SKIP-OK || { echo "stub never reached — flow stopped early"; exit 1; }
rm -rf vendor/llama.cpp/build   # the stub "configure" created the dir; leave the tree clean for Task 2
```
Expect `DRIFT-ABORT-OK` from the drift leg, then `SCRIPT-EXITED-0` + stub-verified `ROCM-SKIP-OK` — the stub marker proves the script ran to exactly the configure step with rocminfo hidden. (The stub's dir side effect is removed afterward; a stub `exit 0` is safe because Task 2's real run configures from scratch anyway.)
